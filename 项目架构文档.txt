            🦊 HuoBot 桌面机器人 — 项目架构文档

Live2D 桌面宠物 | 语音识别 | 克隆音色 | AI Agent | Web 控制面板


====================================================================
                      一、整体架构
====================================================================

  HuoBot 参考 EchoBot 的三层架构设计：

    用户输入（打字 / 按住空格说话）
        │
        ▼
  ┌────────────────────────────────┐
  │  ① 决策层 (Decision Layer)     │
  │  规则引擎 + 轻量LLM分类        │
  │  判断意图，路由分发             │
  └──────┬──────────────┬─────────┘
         │              │
    角色级请求       任务级请求
         │              │
         ▼              ▼
  ┌────────────┐  ┌────────────────┐
  │ ② 角色扮演层 │  │ ③ Agent Core   │
  │ 纯净人设     │  │ 工具调用+技能   │
  │ 快速回复     │  │ 静默执行任务   │
  └────────────┘  └───────┬────────┘
         │              │
         └──────┬───────┘
                ▼
         结果交角色汇报
                │
                ▼
         TTS语音 + Live2D动画
                │
                ▼
      桌面窗口显示 + Web面板同步

====================================================================
                      三、决策层 (Decision Layer)
====================================================================

  文件：core/decision.py

  作用：判断用户输入是"闲聊"还是"执行任务"

  实现：
  ┌─────────────────────────────────────────┐
  │ 1. 快速指令匹配                          │
  │    打开计算器/记事本/浏览器 → agent      │
  │                                         │
  │ 2. 规则引擎（正则匹配）                  │
  │    打开|启动|运行    → agent (open_app)  │
  │    搜索|查一下       → agent (search)    │
  │    你好|嗨|在吗      → roleplay (greet)  │
  │    笑话|讲故事       → roleplay (chat)   │
  │    背诵|诗词         → roleplay (recite) │
  │                                         │
  │ 3. 轻量LLM分类（都不匹配时）             │
  │    让 DeepSeek 判断 agent / roleplay     │
  └─────────────────────────────────────────┘

  路由模式（面板可切换）：
    - agent_first   Agent 优先（任务默认走Agent）
    - auto          自动决策
    - chat_only     纯聊天


====================================================================
                      四、角色扮演层 (Roleplay Layer)
====================================================================

  文件：core/roleplay.py

  作用：以角色身份回复用户，像真人聊天

  核心：纯净的 System Prompt，不含工具信息

  两种人格（联动语音开关）：
    - GPT-SoVITS 开 → 藿藿（胆小软萌狐人少女）
    - GPT-SoVITS 关 → 纯AI（专业简洁助手）

  实现：
    roleplay_reply(user_text, history)
      → 拼接系统提示 + 最近对话历史
      → 调用 DeepSeek 生成回复

    roleplay_report(user_text, agent_result)
      → Agent 执行完任务后
      → 用角色语气向用户汇报结果


====================================================================
                      五、Agent Core
====================================================================

  文件：core/agent.py

  作用：静默执行任务，调用工具，完成后交角色汇报

  工具注册表（ToolRegistry，JSON Schema 定义）：

    search_web(查询词)        → 联网搜索返回结果
    open_app(程序名)           → PowerShell 搜开始菜单打开
    open_website(网站名)       → 打开常用网站
    execute_command(命令)      → 执行系统命令
    write_file(文件名,内容)    → 保存文件到桌面
    read_file(路径)            → 读取本地文件

  实现：DeepSeek 原生 Function Calling
    ┌─────────────────────────────────────┐
    │ LLM 收到用户请求                     │
    │   → 决定调用哪个工具（JSON）          │
    │   → 执行工具                        │
    │   → 结果返回给 LLM                  │
    │   → LLM 决定继续或完成              │
    │   → 最终结果交角色层汇报             │
    └─────────────────────────────────────┘


====================================================================
                      六、语音识别（SenseVoice）
====================================================================

  文件：speech.py + core/asr.py

  方案：阿里 SenseVoice（本地离线，中文极准）

  流程：
    用户按住空格
      → record_until_release 录音（sounddevice）
      → 空格松开 → 停止录音
      → SenseVoice 离线识别
      → 文本进入命令队列

  语音活动检测（VAD）：
    - 音量阈值判断说话起止
    - 停嘴 1.5 秒自动结束
    - 最长 15 秒强制结束

  麦克风检测（core/audio.py）：
    - 扫描所有输入设备
    - 测试哪个能采到声音
    - 自动选择可用设备


====================================================================
                      七、语音合成（TTS）
====================================================================

  文件：tts.py

  方案：GPT-SoVITS（克隆音色）+ Edge TTS（备用）

  GPT-SoVITS 开：
    → 调 http://127.0.0.1:9880/tts
    → 用训练好的角色音色合成语音

  GPT-SoVITS 关：
    → Edge TTS（微软在线语音）

  音色切换（控制面板）：
    → 扫描整合包 GPT_weights_v2Pro + SoVITS_weights_v2Pro
    → 下拉选择已训练的角色


====================================================================
                      八、桌面窗口
====================================================================

  文件：ui/window.py + ui/live2d.html

  技术：PyQt5 + QWebEngineView + PIXI.js

  - 无边框、透明背景、始终置顶
  - 鼠标拖动窗口
  - Live2D 角色渲染（PIXI.js + Cubism SDK）
  - 打字输入框
  - 字幕显示（自适应，持续到语音结束）
  - 情绪状态灯（待机/聆听/思考/说话）

  JS↔Python 通信：
    - 通过 document.title 变化传递指令
    - 输入文字 → title 标记 → Python 收到
    - 空格按键 → title 标记 → Python 收到


====================================================================
                      九、Web 控制面板
====================================================================

  文件：server.py + web/panel.html

  技术：FastAPI + uvicorn（内嵌主进程）

  功能：
    📊 系统状态    语音引擎/AI大脑/运行时间/消息数
    📋 实时日志    对话和Agent执行过程
    💬 对话记录    聊天历史
    ⚙️ 设置       GPT-SoVITS语音开关/音色切换/路由模式
    🧠 AI模型     DeepSeek/Kimi/豆包等多模型切换
    🎭 Live2D     模型预览和切换

  实现：HTTP 轮询（面板定期拉取 /api/state 和 /api/logs）


====================================================================
                      十、多模型 API
====================================================================

  文件：core/provider.py + providers.json

  支持的模型：
    DeepSeek / Kimi / 豆包 / 通义千问 / 智谱GLM / OpenAI / OpenRouter

  实现：
    - providers.json 存各模型 base_url 和 key
    - provider.py 读取当前激活模型
    - 面板切换时热更新客户端
    - 所有模型走 OpenAI 兼容接口


====================================================================
                      十一、数据流（完整链路）
====================================================================

  场景：用户说"打开QQ音乐"

  1. 按住空格说话 → SenseVoice 识别 → "帮我打开QQ音乐"
  2. 进入命令队列
  3. 决策层判断 → agent (open_app)
  4. Agent Core 收到"打开QQ音乐"
  5. LLM 选择工具 open_app("QQ音乐")
  6. PowerShell 搜开始菜单 → 启动 QQ音乐
  7. Agent 返回"QQ音乐已打开"
  8. 角色层用藿藿语气汇报
  9. TTS 合成藿藿语音播放
  10. Live2D 嘴动 + 字幕显示 + 面板日志记录

                      十二、配置文件说明
====================================================================

  config.py：
    SOVITS_BASE      GPT-SoVITS 整合包路径
    TTS_REF_AUDIO    参考音频路径

  providers.json：
    current          当前激活模型
    models           各模型 base_url / model / key


====================================================================
                      十三、启动流程
====================================================================

  huohuo.bat / launcher.py
    ├── 1. 启动 GPT-SoVITS 语音引擎（后台）
    ├── 2. 等待语音引擎就绪
    ├── 3. 启动桌面端 main.py（内含控制面板）
    └── 4. 打印控制面板地址

  main.py
    ├── 启动 Live2D HTTP 服务（18666）
    ├── 启动控制面板服务（18688）
    ├── 创建桌面窗口
    ├── 加载 SenseVoice
    ├── 启用空格监听
    └── 进入 Qt 事件循环
