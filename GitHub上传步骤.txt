====================================================================
              HuoBot 上传 GitHub 步骤
====================================================================

  前提：备份已完成（D:\huohuo v1-backup）
        已创建 .gitignore 排除大文件
        已清除 API Key

====================================================================
                    第1步：创建 GitHub 仓库
====================================================================

  1. 打开 https://github.com
  2. 登录你的账号
  3. 点右上角 + → New repository
  4. 填仓库名：HuoBot
  5. 选 Public（公开）或 Private（私有）
  6. 不要勾选 "Add a README"（避免冲突）
  7. 点 Create repository

====================================================================
                    第2步：本地初始化 git
====================================================================

  打开命令行（PowerShell），执行：

    cd "D:\huohuo v1-desktop"
    git init
    git add .
    git status          ← 检查哪些文件会被上传

  确认 .gitignore 生效：
  应看到 core/ ui/ web/ *.py 等，看不到 models/ vosk-model/ 等

====================================================================
                    第3步：提交
====================================================================

    git add .
    git commit -m "HuoBot 桌面机器人 - 初始版本"

====================================================================
                    第4步：关联远程仓库
====================================================================

  把下面的仓库地址换成你刚创建的那个：

    git remote add origin https://github.com/你的用户名/HuoBot.git
    git branch -M main
    git push -u origin main

====================================================================
                    第5步：验证
====================================================================

  1. 打开你的 GitHub 仓库页面
  2. 确认代码已上传
  3. 确认没有 models/ vosk-model/ providers.json 等文件
  4. 如果误传了敏感文件，立即删除：
     git rm --cached providers.json
     git commit -m "remove api key"
     git push

====================================================================
                  上传后会包含哪些
====================================================================

  ✅ 会上传：
    main.py / launcher.py / server.py / config.py
    speech.py / tts.py / wake_word.py
    core/ (决策/角色/Agent)
    ui/ (窗口+Live2D页面，不含模型)
    web/ (控制面板)
    requirements.txt / README.txt
    .gitignore

  ❌ 不会上传（被 .gitignore 排除）：
    models/           SenseVoice 模型 894MB
    vosk-model/       备用识别模型
    GPT_weights/      训练音色权重
    ui/assets/huohuo/ 版权 Live2D 模型
    providers.json    API Key 配置（让对方自己填）
