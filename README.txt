====================================================================
                    🦊 藿藿 AI 桌面机器人
====================================================================

Live2D 桌面宠物 | 语音唤醒 | 克隆音色 | AI Agent | Web 控制面板

====================================================================
                          核心架构
====================================================================

本项目参考 EchoBot 的三层架构设计：

  用户输入
      │
      ▼
  ┌─────────────────────────────┐
  │  决策层 (Decision Layer)     │
  │  规则引擎 + 轻量 LLM 分类     │
  │  判断用户意图，路由分发        │
  └──────┬──────────┬──────────┘
         │          │
   角色级请求    任务级请求
         │          │
         ▼          ▼
  ┌──────────┐ ┌──────────────┐
  │ 角色扮演层│ │ Agent Core   │
  │ 纯净人设  │ │ 工具调用+技能  │
  │ 快速回复  │ │ 静默执行任务  │
  └──────────┘ └──────┬───────┘
         │          │
         └────┬─────┘
              ▼
        结果交给角色汇报
              │
              ▼
        TTS语音 + Live2D动画
              │
              ▼
      桌面窗口显示 + Web面板同步


====================================================================
                        功能清单
====================================================================

【桌面窗口】
  □ Live2D 角色实时渲染 (PIXI.js + Cubism SDK)
  □ 透明无边框窗口，可拖动，始终置顶
  □ 打字输入（底部输入框，回车发送）
  □ 情绪状态指示灯（绿=待机 蓝=聆听 橙=思考 红=说话）
  □ 字幕显示，持续到语音播放结束

【语音交互】
  □ Vosk 离线中文语音唤醒 - 说"小藿同学"激活
  □ GPT-SoVITS 克隆音色 - 可训练任意角色的声音
  □ Edge TTS 备用语音 - 无需额外安装，开箱即用
  □ 音色切换 - Web 面板一键切换已训练的音色

【AI 大脑】
  □ 多层模型支持 - DeepSeek / Kimi / 豆包 / 通义千问 / 智谱GLM / OpenAI
  □ 三个路由模式 - Agent 优先 / 自动决策 / 纯聊天
  □ 上下文记忆 - 保留最近 40 轮对话
  □ 联网搜索 - Agent 可搜索网页并返回信息摘要
  □ 电脑操控 - 打开程序 / 网站 / 执行命令 / 读写文件

【Web 控制面板】 http://127.0.0.1:18688
  □ 系统状态监控 - 语音引擎 / AI大脑 / 运行时间 / 消息数
  □ 实时日志流 - 对话/Agent/设置日志
  □ 对话记录 - 左右分栏查看历史
  □ 设置调节 - 语音开关 / 唤醒开关 / 路由模式 / 音色切换
  □ 模型切换 - 多 AI 模型热切换
  □ Live2D 模型管理 - 预览 + 切换

【Live2D】
  □ 桌面端渲染 (PyQt5 + QWebEngine)
  □ Web 面板预览 (贴图缩略图)
  □ 支持多模型切换 - 放 assets 目录自动识别


====================================================================
                        快速开始
====================================================================

【源码运行】
  1. pip install -r requirements.txt
  2. 设置 API Key: 编辑 providers.json
  3. python main.py

【便携版】
  1. 解压到任意目录
  2. 双击 藿藿.exe
  3. 浏览器打开 http://127.0.0.1:18688 配置


====================================================================
                      多模型 API 配置
====================================================================

编辑 providers.json，填入对应平台的 API Key：

  DeepSeek     https://platform.deepseek.com
  Kimi          https://platform.moonshot.cn
  豆包          https://console.volcengine.com/ark
  通义千问      https://dashscope.console.aliyun.com
  智谱 GLM      https://open.bigmodel.cn


====================================================================
                      Live2D 模型说明
====================================================================

已有模型：藿藿

添加新模型，放到 ui\assets\新角色名\ 目录：

  ui\assets\新角色名\
  ├── 新角色名.model3.json     模型配置
  ├── 新角色名.moc3             模型本体
  ├── 新角色名.physics3.json   物理引擎
  └── 新角色名.8192\           贴图文件夹
      ├── texture_00.png
      └── ...

重启后 Web 面板自动识别，下拉切换。桌面窗口重启后生效。


====================================================================
                    克隆音色（可选）
====================================================================

需要 GPT-SoVITS 整合包：

  1. 下载：https://hf-mirror.com/lj1995/GPT-SoVITS-windows-package
  2. 解压，双击 go-webui.bat 训练音色
  3. 启动 API：runtime\python.exe api_v2.py
  4. 训练好的权重放到 GPT_weights_v2Pro + SoVITS_weights_v2Pro
  5. Web 面板 -> GPT-SoVITS 音色 -> 选择切换


====================================================================
                    语音唤醒（已内置）
====================================================================

Vosk 中文模型已打包在 vosk-model-small-cn-0.22\ 目录中。
启动后说"小藿同学"即可唤醒，无需联网。

                        操作说明
